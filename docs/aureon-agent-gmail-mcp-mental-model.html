End to end — "list my recent emails"
cli.py builds the MCP server list and spawns node .../multi-email-mcp/src/server.js as a stdio child process.
Server boots, reads MAIL_ACCOUNTS + GOOGLE_OAUTH_* env, loads tokens/vishal.json. Prints ready.
MCPManager connects and discovers 4 tools: list_recent, search_mail, read_message, list_accounts.
LLM (via Ollama) decides to call mcp_gmail_list_recent({account, limit:5}).

Gmail returns real metadata → server serializes to an MCP result → LLM summarizes for Captain.

The OAuth dance — headless athena
athena has no browser. Google's consent flow needs one. The fix was a port-forward tunnel.
On Mac: ssh -L 32807:localhost:32807 radxa@athena — forwards Mac's localhost:32807 to athena.
On athena: set MAIL_ACCOUNTS, GOOGLE_OAUTH_* env, run npm run auth vishal → prints a consent URL.
Open the URL in the Mac browser, sign in, grant read-only Gmail access.
Google redirects to http://localhost:32807?code=... — the SSH tunnel carries it to athena's auth.js, which exchanges the code for tokens.
Token saved to tokens/vishal.json on athena (chmod 600), then copied into the bot's own tokens/ directory.
