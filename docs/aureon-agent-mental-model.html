A message, end to end
"download my recent invoices from gmail" → Telegram reply
Captain sends the message to @aureon_agent_bot. Telegram delivers it via getUpdates, polled ~10s.
channels/telegram.py:_on_message — drops silently if chat isn't allow-listed; routes slash text straight to _on_command (no LLM); otherwise hands off to the router.
Router gets/creates the session (telegram:723865496) and appends the user message.
AgentRuntime.run() fires: require_plan() hard-blocks 3+ step tasks without a plan → maybe compacts history → ContextBuilder.build() assembles the 5 brain files + JIT sections.
ReAct loop, up to 5 rounds: search_mail → read_message (surfaces attachmentId) → download_attachment (writes the PDF) → text summary.
Assistant message saved to session; Telegram edits the placeholder message (1/sec throttle), chunking replies over 4096 chars.
